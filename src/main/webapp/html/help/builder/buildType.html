Common values are <empty>, Debug, Release, RelWithDebInfo and MinSizeRel.

For single-configuration generators (such as Ninja or Unix Makefiles), a non-empty value populates the CMake cache variable -D CMAKE_BUILD_TYPE=<buildType> during the configure step.

For multi-configuration generators (such as Visual Studio, Xcode, or Ninja Multi-Config), CMAKE_BUILD_TYPE is omitted during the configure step and --config <buildType> is passed automatically during cmake --build steps (when Use cmake / withCmake: true is enabled).

If you desire to use a custom build type, you are able to do so. Any custom build type requires additional configuration in CMakeLists.txt.
